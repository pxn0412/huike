# 慧科 · 校园竞赛服务

校园竞赛资料、学生画像与队伍招募的网站原型，当前供本机体验。启动及配置见 [website/README.md](website/README.md)。

## 当前实现（2026-10-02）

- 上传 PDF、Word、图片、TXT 或 Markdown，保存原件并提取正文；扫描 PDF 和图片由已配置的视觉模型识别，长文件显示后台处理进度。
- AI 提取资料身份，系统建议相似的已有比赛；用户可查看已有资料，并明确确认归属后提交。
- 新资料可以新增、逐项更新旧规则、整体替换或保留待确认冲突。原件与历史保留，默认问答使用当前有效证据；知识库切换失败有明确状态和重试入口。
- 已有账号登录、画像对话与草稿确认保存、招募发布及 AI 整理辅助。联系方式由用户填写，不做自动组队、能力评分或站内聊天。

网站比赛问答当前使用按比赛筛选的本地证据和配置模型；平台 SSE 的请求级过滤尚未集成，后续多智能体架构仍是方案。代码上传不代表公网部署完成。
