# 慧科杯 · 校园竞赛服务

为2026年慧科杯准备的校园竞赛服务项目。已加入本地网站原型，支持 PDF 上传、资料确认、本地原文检索、ADP 知识库上传和已发布智能体问答。

运行说明见 [website/README.md](website/README.md)，ADP 接入记录见 [交接与索引](docs/adp/2026-09-19-交接与索引.md)。密钥、用户上传文件、本地数据库和运行日志不包含在仓库中，需在本机配置。当前服务器仅供本机演示。

2026-09-20 审查：本地 41 项测试通过，外部服务在测试中使用模拟调用；仍有同名新版资料误判重复、比赛检索隔离不足、会话上下文丢失、索引状态跟踪及引用处理问题，详见 [审查记录](docs/adp/2026-09-20-代码审查.md)。

## 基本功能

- **竞赛信息理解与问答**：根据学生或老师上传的比赛资料，解释要求并回答问题。
- **学生竞赛画像**：帮助学生整理本人经历、贡献与参与意愿，经本人确认后按授权展示。
- **队伍招募**：学生自行发布招募并公开联系方式，其他学生浏览后自行联系，全程不使用AI。

保留基于画像的比赛推荐。已取消缺口分析、AI推荐队友、自动组队和定向采集，不做站内申请或站内聊天。
