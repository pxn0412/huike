# ADP 黄金评测集（2026-09-19）

用途：知识库上传后做**可复现**的效果回归。每题的"依据块"引自 `慧科杯-知识库块清单.yaml`；同一批题跑两轮（改动前 / 改动后），对比记录。

配套文件：`docs/adp/data/慧科杯-知识库上传-通知2026-06-05.md`、`docs/adp/data/慧科杯-知识库上传-海报2026-09.md`、`docs/adp/2026-09-19-知识库切片与元数据规格.md`。

## 一、判定层（失败要归到层，不然改了也白改）

| 层 | 现象 | 先动什么 |
| --- | --- | --- |
| 解析层 | 回答提到"没有相关资料"，但知识库里明明有 | 文档解析/OCR/切片 |
| 检索层 | 依据块没被召回（问 A 题拿回 B 块） | top-k、rerank、块粒度（规格 §7、§8） |
| 提示词层 | 依据召回了，但答歪、编造、不引用、不并列 | 提示词（诊断文档 §三） |
| 参数层 | 同一问题两次答案不一致、回答被截断 | 温度、max_tokens、模型 |

**通过 = 事实正确 + 依据块正确 + 遵守话术约束**（不编造、不越界、该并列就并列、该说"未载明"就说）。
