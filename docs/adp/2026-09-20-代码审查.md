# 当前网站代码审查（2026-09-20）

本次提交保存当前实现，以下问题尚未修复。审查包括静态调用链、本地测试及不联网模拟复现，不代表本次重新验证了线上服务。

## 当前实现

PDF 本地解析/OCR → DeepSeek 提取资料身份 → 用户确认 → 本地规则切块 → ADP 知识库上传 → 已发布智能体回答。

切块由 `website/chunking.py` 完成，并非 DeepSeek。DeepSeek 另有可选校对建议及未配置智能体时的问答回退。

## 待修问题

1. P1：远端文件名仅用标题与发布日期，导致不同内容、不同比赛的同名资料可能被跳过上传；应使用稳定资料标识并核对内容。
2. P1：比赛范围只通过提示词约束，未执行检索过滤或引用归属校验。
3. P1：每次问答新建 ConversationId，页面历史没有传回智能体，追问丢失上下文。
4. P2：SaveDoc 登记成功就显示已入库，没有跟踪学习、索引成功或失败。
5. P2：回答出现“未提及”等词即隐藏全部引用，可能删除有效依据。
6. P2：空 SSE 响应的评测占位文字被当成正常智能体回答。

此外，本地关键词片段与平台引用尚未建立逐条 PDF 页码映射。
