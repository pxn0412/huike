## 3. 必修 1 项：占位文字被当成画像内容（真实模型触发，离线假数据测不出）

实测复现（真机 B 的原始回答）：`· 希望参与什么：（未提及）  · 正在学习 / 希望尝试什么：（未提及）`

服务端 `demo.parse_profile` 解析后得到：

```json
draft   = {"experiences": "参加课程 AIGC 短片项目；做过演示视频\n本人负责：演示视频剪辑",
           "participation": "（未提及）", "learning": "（未提及）"}
changes = ["新增“做过什么 / 本人负责什么”", "新增“希望参与什么”", "新增“正在学习 / 希望尝试什么”"]
```

后果三条：① 画像里出现"希望参与什么：（未提及）"这种**假内容**；
② 「本次修改」**误报**成改了三个字段（模型自己只说了改一个）；
③ 用户直接点保存，**假内容进库**。

修法（改 `website/demo.py` 的 `parse_profile`，不用动平台）：

1. 值清理后命中占位词表（`待补充 / 未提及 / 暂无 / 未知 / 无 / 未填写 / 未说明 / 未提供 / N/A / — / -`）
   → 视为空，**该字段不出现在 draft**；
2. 只有真内容才算进 `changes`；
3. 顺手在 `demo.organize` 拼给 B 的指令里加一句：
   "没提到的类别请直接省略，不要输出（未提及）、待补充这类占位文字"；
4. 补一条离线测试：夹具回答里带 `（未提及）` / `待补充` → 断言 draft 不含该字段、changes 不含该项。
   （`test_demo.py` 现在**没有任何占位文字用例**，这就是漏网的原因。）
