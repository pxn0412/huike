# 后续版本候选：队伍招募

状态：普通产品功能；不属于慧科 Agent v0.1 的 Tool、路由或能力验收范围，但可作为产品 Demo 的非 AI 功能单独展示。用户已确认本模块全程不用AI，联系路径采用“公开联系方式后自行联系”。原文件名暂保留，字段及展示细节仍待完善。

## 1. 功能定位

学生自行发布招募及联系方式，其他学生查看招募内容和允许展示的画像，自主决定是否联系。双方在站外沟通，商定是否组队及具体分工。

## 2. 解决的问题

提供集中了解“谁正在招人、准备做什么、希望找什么队友、怎样联系”的入口。招募内容与02画像帮助双方了解彼此。

## 3. 用户流程

发布者填写招募 → 主动填写并确认公开自己的联系方式 → 发布 → 其他学生浏览列表和详情、查看获准展示的画像 → 使用公开联系方式自行联系 → 双方自行沟通。发布者可编辑或关闭招募。

已确定不使用站内申请、接受或拒绝流程，不扩展站内聊天。查看联系方式不代表实际联系、组队成功或完成官方报名；系统不自动追踪站外沟通结果。

联系方式的公开由发布者主动决定，不自动取用账户信息，也不随画像展示授权自动公开。具体联系方式类型与呈现形式待定。

## 4. 输入内容

以下是招募内容建议，除已确定需要公开联系方式外，其他字段及必填项待完善：

| 内容 | 用途 |
| --- | --- |
| 参加的比赛 | 为哪场比赛找人 |
| 招募标题 | 快速说明招募主题 |
| 项目想法或参赛方向 | 准备做什么，尚未确定可如实说明 |
| 希望队友参与的事情 | 发布者自己表达需求 |
| 招募人数 | 希望补充几人 |
| 发布者及允许展示的画像 | 帮助其他学生了解发起人 |
| 发布者主动公开的联系方式 | 供感兴趣的学生自行联系 |

时间安排可写入补充说明。浏览者不需要提交站内申请或申请者档案。

## 5. 系统处理逻辑

保存、展示学生提交的招募与联系方式，提供列表、详情及编辑、关闭招募等基本管理。简单筛选项后续确定。

本模块全程无AI，不进行缺口分析、AI推荐队友或自动组队，不生成招募需求、匹配理由、评分或角色分配。

02可以使用AI准备画像，03只展示本人填写或明确认可且允许展示的当前内容。修改或隐藏画像后，后续展示同步更新。02画像整理不强制插入03发布或浏览流程。

历史GitHub案例只作招募内容展示的参考，不引入申请状态，也未选定、运行或集成复用代码。

## 6. 输出结果

招募列表、招募详情、获准展示的画像以及发布者主动公开的联系方式。建议招募状态分为“招募中”和“已结束”，由发布者维护；不设置申请结果或自动组队成功状态。

学生自主选择和联系，系统不保证双方合适。关闭招募也不意味着系统已经验证组队成功。
