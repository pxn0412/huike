# 慧科本地网站实施计划

目标：先交付可运行的真实文件流程，再连接混元；不把页面原型或本地关键词检索称为 AI 问答。

已确认交互：添加 PDF → 提取文本和识别候选 → 用户确认比赛归属 → 比赛空间 → 通知列表与侧边原文查看。取消临时提交不生成正式资料。新通知不覆盖旧通知。

代码位置：当前可写工作区 `website/`。桌面 `huike/` 是另一份文档仓库，本轮不覆盖其内容。

技术：浏览器原生 HTML/CSS/JavaScript；Python 标准库 HTTP 服务、SQLite；已安装的 pypdf 负责按页提取文本。服务仅监听 127.0.0.1。所有数据保存在 website/data，排除在版本控制外。
