# 文件识别改进

范围：上传文件的文字提取。保留原文件、比赛归属确认和现有问答路径。

1. 验证独立 DeepSeek 视觉模型，禁止修改全局问答模型。
2. 图片使用视觉转录；拒绝截断、异常格式和模型明确报告无法辨认的结果。
3. PDF 保留正常文字层；扫描、乱码及含图片页面按原页识别。
4. Word 保留段落和表格，在原段落位置补充嵌入图片文字；TXT/Markdown 原样读取。
5. 记录实际提取方式和未完成位置；失败不可静默回退到低质量 OCR。
6. 离线测试只模拟服务；真实探针不确认入库、不上传知识库。

限制：识别不是人工认证；模型未报告的错误仍可能存在。旧资料不自动重写，重新上传才走新流程。
