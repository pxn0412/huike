# 慧科 · 本地体验版

双击本目录的 `start.cmd`，浏览器会打开 http://127.0.0.1:8765 。重复启动会复用已经运行的服务。当前仅供本机体验，不是已经部署的公共网站。

## 怎么体验

1. 先**注册**或用已有账号**登录**（邮箱或手机号 + 密码，密码至少 6 位；注册与登录分开，注册要填显示名称）。登录后画像、招募、上传的资料都记在这个账号下；**没登录时所有接口都会被拒绝**。
2. 点击“上传比赛通知”，选择一个 PDF。
3. 核对比赛名称、届次、发布时间等。右侧可翻页查看原 PDF。点击“确认添加”才正式保存；取消不创建比赛或正式资料。
4. 进入比赛空间：**问答和资料在同一页**。直接问“一个人能参加吗”“需要提交材料吗”；需要翻原文时点开标题下面的「这场比赛的全部资料（N 份）」折叠行。
5. 点击原文卡片打开对应页。新上传文件保留旧文件；同一比赛中完全相同的文件不重复创建。
6. 确认添加后，这份资料会**自动切成块送进 ADP 知识库**（需要 `.env` 里的腾讯云密钥与知识库 ID）。比赛空间里每份资料都会显示“知识库：已进知识库（N 块）· 文件名”；没成功的可以点“重新上传到知识库”重试。

## 已实现与限制

- 真正保存 PDF、按页提取正文，SQLite 持久化比赛与资料；刷新后仍存在。
- **登录**：邮箱或手机号 + 密码（pbkdf2 加盐摘要，不存明文），账号绑定本机身份，换设备登录还能看到自己的画像与招募；除 `/api/status` 与 `/api/auth/*`，其余接口未登录一律返回 401。不再有“学生 / 老师”自选身份。
- 本机 Windows 中文 OCR 可识别扫描页，当前每份文件最多处理 20 个扫描页。OCR 可能错字，界面明确提示核对原图；未识别页不作为已读内容。
- PDF.js 负责侧栏翻页、指定页定位、缩放；页码是 PDF 的物理页序号，不承诺与印刷页码一致。
- 问答优先由**已发布的智能体**回答（`.env` 里的 `ADP_APP_KEY` / `ADP_CHAT_URL`）：网页里的答案与评委扫码问到的是同一个。**同一个浏览器在同一场比赛里是连续会话**（追问接得上上文），"新会话"按钮只重置当前比赛；换人或换比赛各算各的。引用按平台给的角标区分"回答依据"与"检索到的资料（回答未使用）"，没有角标就明说"本次回答未标注可核对引用"；引用优先指回本地资料（能唯一定位才给 PDF 页码，否则只到文件级）。智能体不可用时不会假装回答，而是提示失败并只展示本地原文。没配智能体时退回本地模型（DeepSeek），再没有就只展示关键词检索结果。
- **比赛页只有一页**：提问是右下角的气泡（"我"），回答是左边的卡片（"AI"）；用时、引用、本地原文片段**收在回答后面的同一块「依据与原文」里，原文片段排在最下面**（不再有"全部通知 / 问答与原文"两个 tab，资料收成标题下面的一行折叠）。答完自动停在最新一轮的结尾（输入框就在屏幕底部），不用从头往下滑；画像页和招募协助的对话也一样落到最新一条。
- **两个智能体分工**：①「竞赛资料问答助手」（主应用，挂知识库，负责按比赛资料回答）；②「学生画像助手」（第二个应用，**不挂知识库**，只依据学生自述整理画像，用于组队招募）。画像智能体在提示词里被明确要求：不判断能否参赛，遇到这类问题转给资料问答助手。左侧导航的"我的画像"页调第二个应用（`ADP_PROFILE_APP_KEY`）。
- **画像页是对话式的**：先和画像助手聊（双方消息存本机库，刷新或换台电脑登录都还在），聊好再点「整理成画像草稿」；草稿在点「确认并保存」之前不会动正式画像。「清空对话」只清聊天记录和这轮对话上下文。
- **画像谁能看到**：画像页只有你自己看得到，也只有你能改（没有"是否公开"开关）；**发布招募后，这条招募的详情页会一并展示你的已确认画像**——组队要先看得见人，但只列经历与方向，不做等级/评分。发布者没填过画像，详情页会明说"还没有画像"；广场卡片上标一句"已填写画像"。
- **招募写不出来时**：在「项目想法」旁边点「和 AI 一起完善」——右边会展开一块面板：先给出**这场比赛的要求**（比赛助手回答，带引用文件名），然后画像助手陪你聊；聊完点「整理到招募表单」，会先给三栏预览（招募标题 / 项目想法 / 希望队友参与，逐栏可勾选），确认后才填进表单，还能手动改，最后点「确认发布」才公开。这中间**主画像只用来理解你**，不会被写进招募、也不会被改动；人数和联系方式自己填。依据卡和对话再长也只在**面板里滚**（面板高度跟左边表单一样、两边底部对齐，不把整页拉长；标题栏钉在面板顶部，随时能点「收起」），新回复和预览出来时面板自动落到最新一处。
- **输入框不再弹浏览器的“保存的信息”**：提问框、画像和招募表单都带 `autocomplete="off"`，避免演示时弹出浏览器替你存下的历史输入。浏览器里**已经存过的旧记录**要在浏览器设置（自动填充/表单数据）里清一次，页面这边删不掉。登录页保留正常的账号与密码自动填充。
- 已实现可选模型适配代码。配置有效服务后可调用模型提取资料身份及生成带引用回答；引用 ID/原文须通过后端核对。真实云端调用尚未验证。
- 确认资料后会调用腾讯云 ADP 开放接口，把切好的块写进知识库（`DescribeStorageCredential → COS PUT → SaveDoc`，走旧版 `lke` 接口）。这一步失败**不影响**本地入库，状态存在资料表的 `kb_*` 列里。启动时会先**认领**知识库里已经有的文档（把平台文档 ID 与文件名记回本地，老资料也能翻回原文，且不会被重复上传），再补传本地缺的。知识库文件名用技术名 `{比赛ID}-{资料ID}-{上传内容哈希前12位}.md`：内容没变就是真重复（跳过），内容变了就是新版本（正常入库、旧版保留）；同时给平台传 `DuplicateFileHandles` 按内容哈希兜底判重。想关掉自动上传，在 `.env` 里加 `ADP_AUTO_UPLOAD=0`。
- 当前赛道输入只是资料备注。问答范围是当前比赛，未实现按赛道过滤；不能当作完整资格审查产品使用。
- 身份分两层：**姓名和学生/教师身份由用户自行选择**，只作为资料上的展示标注（不参与任何权限判断）；**上传者归属由服务端签发的匿名 Cookie 判断**（`HttpOnly`，前端读不到也改不了），只有上传者本人能撤销自己发起的版本替换。清掉 Cookie 或换浏览器就失去撤销权（Demo 取舍）。没有正式登录、多人权限、画像、队伍招募、公共部署。
- AI 提供的引用可以校验存在性，但这不等于语义正确；仍需针对规则冲突、时间和资格条件开展真实模型验收。

## 可选 AI 配置

将 `.env.example` 复制为 `.env`，在本机编辑服务地址、模型名称和密钥。不要提交或分享 `.env`。刷新网页可重新读取配置状态。字段全部填写只表示已配置，不代表已经连通或模型可用。

示例接口依据：[DeepSeek 官方 API 文档](https://api-docs.deepseek.com/)。本适配器只要求服务商提供 OpenAI 兼容的 `/chat/completions`，换成其他兼容服务商只需改这三个字段。模型服务开通与当前可用模型以用户实际控制台为准。无需为了看页面先配置密钥。

## 文件位置

- `server.py`：本地 HTTP 接口与静态资源；签发/读取匿名身份 Cookie。
- `identity.py`：匿名会话身份（只用于判断"是不是同一个人上传的"，不做认证）。
- `clients.py`：外部平台边界（`KnowledgeBaseClient` / `AgentClient`）。
- `store.py`：比赛、临时上传和正式资料存储（表结构带版本号与迁移器）；比赛范围内检索；按块入库（`chunks` 表），确认后同步到 ADP 知识库。
- `adp.py`：把切好的文本送进 ADP 知识库（`--check` 自检 / `--list` 列文档 / `--all` 批量提交 / `--delete` 删文档 / `--verify` 验引用）。
- `chunking.py`、`kb.py`：规则切块，并生成可上传知识库的 Markdown 与块清单。
- `parsing.py`、`ocr.ps1`：PDF 解析与本地扫描文字识别。
- `ai.py`：可选的模型接入、资料身份草稿、引用核验。
- `static/`：首页、比赛库、上传确认、比赛空间与 PDF 查看器。
- `data/`：本机数据，不进入 Git。
- `artifacts/`：浏览器测试截图，不进入 Git。

## 开发与验证

首次迁移到其他电脑：Python 3.12，执行 `python -m pip install -r requirements.txt`；Node.js 执行 `npm install`。Windows OCR 还需要 Poppler 和系统中文 OCR 语言；缺少时保留文件并提示未识别。

启动：`python server.py`。端口变量 `HUIKE_PORT`，数据目录变量 `HUIKE_DATA_DIR`。

改 `static/` 下的文件刷新页面即可（响应带 `Cache-Control: no-store`）；**改任何 `.py` 都必须重启服务**——Python 只在启动时导入一次，否则页面会变成"新前端 + 旧后端"（例如招募详情明明有画像却写"还没有画像"）。服务端在 `/api/status` 里用 `code_stale` 报出自己比磁盘上的代码旧，页面顶部会出现一条黄底提示条，正常重启后自动消失。

验证：`python -m unittest test_store -v`；`node check-ui.cjs`。浏览器脚本当前使用本机已安装 Chromium 路径，并从用户桌面读取慧科杯通知，测试数据使用独立临时数据库。

默认隐藏后台启动。若需停止，在任务管理器中核对命令行，只结束本项目 `server.py` 对应的 Python 进程；不要结束无关 Python 程序。
